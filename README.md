# 战略发展分析工作台 (Strategic Development Analysis Workbench)

面向总部职能部门的"决策副驾"工作台：对各行各业业务合作/投资项目做接洽前后的可行性初评、合作点挖掘与方案设计。

> **术语**：「项目」＝待评估的业务合作/投资项目（deal）；「分析 / 研究」＝本工作台对一个项目的一次评估（代码类型 `Analysis`）。

- 定位与工作方法见《业务项目对接工作框架 · 定稿 v1》（框架文档）。
- 开发方案见 [`docs/开发方案.md`](docs/开发方案.md) 及 `docs/详细设计-*.md`。

## 核心特性

- **填 API Key 即用 · 多模型**：Claude / GPT / DeepSeek / 智谱 / KIMI，按阶段选模型；硬结构化步骤可路由到任意模型（JSON mode + 本地校验）。
- **两轴工作法**：评估维度 × 时间阶段（定框 → 调研前 → 洽谈中 → 洽谈后）。
- **判断初稿而非终稿**：AI 交出带立场、依据、把握度、可反驳点的判断卡片，供对话审改。
- **行业分析对齐深度基准**：以《算力租赁·行业深度研究与项目评估》为 few-shot 与导出模板。
- **交易结构四流 + 合规探测**：确定性规则 R1–R7 报红/黄灯（不靠 AI 判红）。
- **多格式导出**：HTML / Word / PDF，以"方便阅读"为目标。
- **交付物库**：行业分析、企业画像作为可复用的半耐用资产。
