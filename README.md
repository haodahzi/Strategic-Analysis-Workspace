# 业务项目对接工作台 (Business Project Docking Workbench)

面向总部职能部门的"决策副驾"工作台：对各行各业业务合作项目做接洽前后的可行性初评、合作点挖掘与方案设计。

- 定位与工作方法见《业务项目对接工作框架 · 定稿 v1》。
- 开发方案见 [`docs/开发方案.md`](docs/开发方案.md)。

## 核心特性（规划）

- **填 API Key 即用**：本地优先，客户端界面，设置页填好 Key 与模型即可开始。
- **两轴工作法**：评估维度 × 时间阶段（定框 → 调研前 → 洽谈中 → 洽谈后）。
- **判断初稿而非终稿**：AI 交出带立场、带依据、带把握度、带可反驳点的判断，供你在对话中审改。
- **多格式导出**：Word / HTML / Markdown / PDF，以"方便阅读"为目标。
- **知识库沉淀**：行业分析、企业画像作为可复用的半耐用资产。
