# 详细设计 · 多模型适配 与 导出模板（含参考样例）

> 覆盖两件事：
> 1. **多模型适配**——设置里保留 Claude / GPT / DeepSeek / 智谱 / KIMI 等多提供商 Key，按阶段选模型。
> 2. **导出模板**——以你上传的《算力租赁·行业深度分析》样例为**规范交付格式(HTML)与设计系统**，HTML 优先、派生 Word/PDF。

---

## 一、多模型适配

### 1.1 目标
- 设置中心保留**多提供商 API Key**，可扩展；每个阶段可各自选"提供商 + 模型"。
- 关键"必须机器可解析"的步骤（四流抽取、前提假设映射）优先用能力最稳的提供商（默认 Claude）。

### 1.2 提供商与接口风格
大部分国产/OpenAI 系模型都提供 **OpenAI 兼容**端点，所以只需两个适配器覆盖全部：

| 提供商 | 接口风格 | 典型模型 | 备注 |
|---|---|---|---|
| Claude(Anthropic) | Anthropic Messages | `claude-opus-4-8` / `claude-fable-5` | 默认；能力最全 |
| GPT(OpenAI) | OpenAI Chat Completions | 以官方为准 | — |
| DeepSeek | OpenAI 兼容 | `deepseek-chat` / `deepseek-reasoner` | 自配 base_url |
| 智谱 GLM | OpenAI 兼容 | `glm-*` | 自配 base_url |
| KIMI(Moonshot) | OpenAI 兼容 | `moonshot-*` / `kimi-*` | 自配 base_url |
| （可扩展） | OpenAI 兼容 | 通义/豆包/百川… | 加一行配置即可 |

### 1.3 适配层
两个适配器 + 一个统一接口，Webview 内实现，HTTP 全走 `tauri-plugin-http`（免 CORS）：

```ts
interface LLMProvider {
  id: string;                 // claude | openai | deepseek | zhipu | kimi | ...
  style: "anthropic" | "openai";
  baseUrl?: string;
  models: string[];
}

interface LLMClient {
  stream(req: ChatRequest): AsyncIterable<Chunk>;                 // 流式统一
  structured<T>(req: ChatRequest, schema: JSONSchema): Promise<T>; // 结构化统一
}
// AnthropicAdapter：Anthropic SDK + output_config.format / strict tool
// OpenAICompatibleAdapter：OpenAI SDK(自定 baseUrl) + JSON mode / function calling
```

### 1.4 能力对照与优雅降级
工作台围绕 Claude 能力设计，非 Claude 提供商取**通用子集**：

| 能力 | Claude | OpenAI 兼容(GPT/DeepSeek/GLM/KIMI) |
|---|---|---|
| 流式 | ✅ | ✅ |
| Prompt Caching | ✅ 原生前缀缓存 | ❌ → 前端精简/复用 prompt，不依赖服务端缓存 |
| 结构化输出 | ✅ `output_config.format` / strict tool | ⚠️ JSON mode / function calling + **本地 schema 校验 + 失败重试** |
| 推理档(effort/adaptive) | ✅ | ⚠️ 各家不一（如 `deepseek-reasoner`）→ 映射到统一"深/浅" |
| 长上下文 | 1M | 各家不一，超限时分块 |

> 建议：**四流抽取、前提假设映射表**这类硬结构化步骤默认走 Claude；散文类（行业分析、企业画像）可自由选提供商。

### 1.5 按阶段路由 & 密钥管理
- 设置里为每阶段（Step0 / 行业分析 / 画像 / 问题清单 / 洽谈后）指定"提供商+模型"，默认全 Claude，行业分析可配更强档。
- 每提供商一套 `{apiKey, baseUrl?, models[]}` 存 **OS 密钥库**，逐个**连通性自检**；Key 按需读入内存，不入库、不进持久层。

## 二、导出模板（以参考样例为规范格式）

**规范交付格式 = 富样式 HTML**，采用上传样例 `docs/参考样例/算力租赁-行业深度分析-样例.html` 的设计系统。HTML 优先（阅读第一），Word/PDF 由它派生。该样例同时是框架 §3 的行业分析 few-shot 范本。

### 2.1 设计系统组件库（直接沿用样例，映射回框架）

| 组件(样例 class) | 用途 | 对应框架/交付物 |
|---|---|---|
| `hero` + `eyebrow` + `badge` | 报告头 + 口径/免责声明 | 决策主心骨、**口径透明**（"口径差异大·仅供参考"） |
| `nav`(sticky) | 顶部 TOC 导航 | 阅读优先 |
| `part` / `chapter` | 分篇/分章 | 结构规整、警惕退化成填空模板 |
| `card` / `g2·g3·g4` / `card-val` | 要点卡 + 关键数字（`card-sub` 标口径） | **量化区间 + 口径透明** |
| 段位分化 `card` | 谁赚辛苦钱 / 谁赚利润钱 | **能劈开行业的分层轴** |
| `insight`(dark/gold/teal/red)、`anno` | 主张 / 提示 / 对项目方的含义 | **有立场、不和稀泥** |
| `mrow`(bar) | 指标条对比 | 量化对比（毛利/利用率） |
| `table`(tr-hi/lo/warn) | 分类/对照表 | 竞争格局、计费方式 |
| `timeline`(tl) | 周期/时点演进 | **时点/周期透镜** |
| `quote`（利润公式，红色变量） | 命门变量高亮 | **点出命门变量** |
| `chain`(三列) | 产业链定位（红=本环节） | 我方在链条中的位置 |
| `diagram`(内联 SVG) | **交易结构图（五角色/四流）** | 交易结构图收口件 |
| `chk`(⚑ 危险信号) | 尽调红旗清单 | **合规红灯探测器**（见交易结构详设） |
| `verdict`(bull/bear/note) | 结论收口（利多/利空/存疑） | **判断卡片**（立场/依据/存疑） |
| `@page` + `@media print` | A4 打印级排版 | **PDF 导出**开箱即用 |

> 样例里的 `chk`（危险信号）≈ 我们的合规红灯清单；`verdict` 的 bull/bear/note ≈ 判断卡片的立场+依据；`diagram` 的五角色图 ≈ 四流交易结构图。三者直接复用，省去从零设计。

### 2.2 导出管线

```mermaid
flowchart LR
  LLM["LLM 产出<br/>(结构化数据 / HTML 片段)"] --> H["富样式 HTML<br/>(规范格式·设计系统)"]
  H -->|直接保存| HTML["HTML 文件"]
  H -->|WebView 打印(内置A4)| PDF["PDF"]
  H -->|html-to-docx + 图光栅化| WORD["Word .docx"]
```

- **HTML**：即规范格式，直接保存。
- **PDF**：WebView 打印——样例已内置 `@page A4` + `@media print`（卡片 break-inside:avoid、表头重复、隐藏导航），打印级排版开箱即用。
- **Word**：`html-to-docx` 类库转换；SVG/图先**光栅化为 PNG** 嵌入；`chain`/`g4` 等复杂网格在 Word 里**降级为表格/图片**（保内容、容许排版简化）。Word 保真度不够时后置可选 Pandoc。

### 2.3 LLM 如何产出这套 HTML（两种方式）

| 方式 | 做法 | 适用 |
|---|---|---|
| (a) 直接产出 HTML 片段 | 约束 LLM 只用组件库的 class 白名单，产出后**校验 class + 结构** | 行业分析等长文（快、灵活） |
| (b) 产出结构化数据 → 前端模板渲染 | LLM 出 JSON（判断卡片/表/四流），前端套模板成组件 | 判断卡片、四流、红灯清单（可控、必解析） |

> 建议：**长文用 (a)+校验；关键结构件用 (b)**。两者都落进同一套 HTML 设计系统，导出一致。

### 2.4 阅读优先细节（贴合"方便阅读为目标"）
CJK 字体（Noto Serif/Sans SC）、行距 1.75、sticky TOC、可折叠推理、口径 badge、A4 打印样式、红灯高亮可点开判断卡片。
