01
EXECUTIVE SUMMARY
核心结论：一页看懂算力租赁

先把骨架讲清楚。算力租赁的本质，是用重资产（GPU 服务器）换现金流的"数字包租"生意——把"买服务器 + 建机房 + 招运维"的一次性重投入，转化为客户按需支付的运营成本。但 2024 年之后，它已经从"囤卡收租"演变为拿卡资源、资金实力、客户锁定、运维调度四种能力的多维较量；同时，这个赛道里真生意与纯炒作、甚至骗局高度混杂。

十条要点
本质
重资产吃现金流。上游拿卡、中游运营、下游消纳，算力租赁位于中游，是把上游算力"整合成按需租用服务"的一层。
需求切换

强周期

拿卡为王
出口管制下高端英伟达卡一卡难求；能否稳定拿到货、能否真租出去，是两条决定项目生死的确定性。
国产变量
英伟达机柜出租率超 90%，国产卡出租率偏低——瓶颈在 CUDA 生态。2026 下半年昇腾 950 系列或成放量拐点。
头部集中
利通、润泽、协创等一线厂商同时握有资质、重资产与大客户长约；资源与订单向少数头部集中，"赢家通吃"轮廓浮现。
阶段性暴利
2026 Q1 头部预告归母净利 6–8 亿元、同比增 280–400%；但与"价格高位 + 折旧未充分体现"有关，需看穿。
最大的坑
空转套利、壳公司毁约、概念炒作与融资性贸易——已有上市公司数十亿"算力大单"零交付被证监会立案。
判断准绳
评估一个项目：先定位环节 → 再验货源与客户两端是否真实 → 穿透经济性 → 识别真做还是蹭概念。

02
DEFINITION
算力租赁是什么：定义、分类与本质

算力租赁（也叫 GPU 云、算力云）指：按 AI 应用的需求，把 GPU 等计算资源做成一种"服务"，按规格/时长租给企业和个人，而不是让用户自己买服务器、建机房、运维硬件。要理解它，先分清三组概念。

2.1　算力的三种分类
类型核心典型场景
通用算力CPU 为核心网站、数据库、企业 IT、日常云服务
智能算力GPU / AI 芯片为核心AI 大模型训练与推理 —— 算力租赁的主战场
超算算力高性能计算（HPC）气象、基因、材料、流体仿真等科研工程

市场上说的"算力租赁"，几乎专指其中的智能算力（GPU）这一块。

2.2　训练 vs 推理：先分清的分岔
2026 年最大的认知差

训练追求极致的单集群规模与稳定性，依赖高端卡与高速互联；推理看重部署成本、时延、并发与单位 Token 成本，可用中端甚至国产卡。随着大模型转入应用规模化，推理已成增量主力——它深刻改变了芯片选型、机房设计与商业模式，也让国产卡有了用武之地。

2.3　卡型分层：直接决定经济性
高端训练卡
H100 / H200 / B200 / B300。受美国出口管制，国内只能买特定或"阉割版"型号，一卡难求、价格坚挺——是稀缺资源与议价权的来源。
中端卡
A100 / A800 / H800。上一代主力，2025 年价格已腰斩；二手 A100 仍高达 70–80 万元/张。
消费级
RTX 4090 / 5090。跑推理、AI 绘图，性价比高，是"小卡"市场主力。
国产卡
华为昇腾 910B / 950 系列等。政策友好、推理优选，但生态是短板——"能用"到"好用"仍有距离。
2.4　本质：同样卖算力，分两个段位
"二房东"（裸金属出租）
买卡、上架、收租。门槛只有资金，谁都能干。毛利薄（约 20%）、强周期，估值按 PB（资产）给。单纯囤卡收租的模式在买方市场里已经很难持续。
"云厂商"（算力+调度+服务）
靠软件调度把碎片化推理需求拼在一起，把利用率干到 80–90%，再叠加 MaaS、Token 分成、运维调优等增值服务。毛利 60%+，估值按 PS（收入）给。转租赚辛苦钱，服务赚利润钱。
03
DEMAND
需求侧：谁在租、为什么租

这一轮景气的根本驱动力，是生成式 AI 对算力近乎指数级的需求，以及"买卡又难又贵、不如直接租一整套集群"的天然经济性。

规模
2024 年国内智算租赁市场约 1480 亿元（同比近 +90%），2025 年破 2000 亿，2026 潜在收入约 2600 亿元，后续以 20%+ 增速增长。全国已建成 42 个万卡级智算集群。
下游结构
高度集中：互联网 + 大模型约 60%+，政府约 10%+，金融/医疗/教育/制造各约 4–6%。少数互联网大厂的资本开支节奏，几乎主导整个行业景气。
Token 经济
推理需求已是训练的 10–15 倍。带"深度思考"的模型单次回答消耗 Token 数是过去的 5–10 倍；某头部 App 日均 Token 消耗较两年前增长约千倍。付费用户越多、任务越复杂，算力消耗越快。
成本曲线
单位算力/推理成本快速下降。这既扩大应用空间，也意味着高价买入的算力资产可能快速贬值——是评估任何重资产项目的必要变量。
对项目方的含义

需求的真实性最终锚定在少数大客户身上。一个项目的下游若不是"互联网大厂/头部大模型公司/有真实预算的政企"，而是来路不明的中小主体或过桥转租，其需求确定性要打上大大的问号。

5.2　强周期：卖方市场 ↔ 买方市场来回切
2023 – 24 初
卖方市场
供不应求，H100 租金一度冲到 8 美元/小时；押三付一、押二付一，回本可短至 1.5–2 年。
2025
买方市场（冷静期）
供给过剩、价格腰斩；预付费消失，服务商须先垫资建池、客户落地后按实际使用付租；押付比降到押一付一，回本拉长至 3–4 年，部分项目回不了本。
2026
重回卖方市场
B 卡需求突出、供应偏紧，月租赁价格普遍上涨；掌握稳定货源者定价主动权更大。高景气预计延续至 2027。
对项目方最重要的一句

同一家公司、同一批卡，不同时点签的订单，盈利可能天差地别。评估任何项目，都要问清"这单是在什么周期、什么价位锁的"，并纳入价格回落的情景做压力测试。

5.3　国产替代：旧王牌贬值、新能力待补位
一个黑色幽默的现实

装了英伟达 GPU 的机柜出租率超 90%，国产 GPU 服务器出租率却偏低——核心瓶颈不是硬件，而是 CUDA 十几年沉淀的软件生态。大量自建智算中心厂房已建好，却因"无卡可上"或"上了国产卡租不出去"而空置。

拐点信号

Token 经济爆发后算力可按"每百万 Token"计价，利好国产卡生态；华为昇腾 910B/950 也已一卡难求。业界预期 2026 下半年昇腾 950 系列或成放量拐点，焦点在实际适配——能否从"能用"跨越到"好用"。谁能率先做好国产卡集群的调优运营，谁就能建立新护城河。

5.4　头部集中：赢家通吃轮廓浮现

在全球四大科技公司 2026 年合计约 7000 亿美元 AI 资本开支的背景下，中小参与者在供应链博弈中天然处于劣势。资源与订单进一步向同时握有英伟达资质、重资产基础设施、稳定大客户长约的一线厂商集中（如利通电子、润泽科技、协创数据）。从业者普遍判断：2026–2027 加速洗牌，低端纯二房东必死，有服务、有技术、有本地化能力的中端服务商才能活下来。海外新型云厂商（CoreWeave、Oracle 等）以巨额资本开支与在手长约扩张，是这套模式已被验证的对照。

MODEL & ECONOMICS
商业模式与经济性：钱好不好赚
6.1　三种计费方式
模式计价单位适用客户
单实例整租每台 / 每月（单台标配 8 张 GPU）长期稳定使用大规模 GPU 的客户
按算力规模租赁每 P / 每年（国内大单最常用）按需选规模、弹性配置的客户
按 GPU 卡时租赁每卡 / 每小时短期、临时、突发需求；推理/绘图

更上层还有 MaaS（模型即服务，按 Token/调用量） 与 Token 分成（房东变合伙人）——这是毛利最高、也是行业演进的方向。

6.2　利润公式已经变了
利润 =（单价 × 利用率）－（运维 + 获客）－ 折旧—— 利用率是最致命的变量

成本结构上，主要成本是买服务器，其中 70–80% 是算力卡，折旧周期一般 3–4 年，加机房租金、电费与运维。若利用率上不去（行业普遍 40% 以下连电费和折旧都覆盖不了），四年后卡就是废铁。裸机租赁毛利约 20%；通过调度把单卡利用率从约 58% 提到 95%+、并叠加推理与 MaaS，头部综合毛利率可到 60%+。

6.3　回本与收益率（对价格极度敏感）

乐观口径下，GPU 资产约 2.5 年 收回成本；买方市场下部分项目 3–4 年，谈判中常把"三年后 30% 残值"纳入收益测算。收益率对租金极其敏感——以一个偏旧的示意模型为例：租金约 4.5 美元/小时时 IRR 超 20%，跌到约 2.85 美元时仅约 10%，低于约 1.65 美元投资者将面临严重亏损。结论不是"能赚多少"，而是"盈亏高度依赖签约价位与利用率"。

阶段性高景气，但要看穿

2026 年一季度一批核心算力企业净利润同比普遍翻倍以上（头部预告归母 6–8 亿、同比 +280–400%）。但这与"价格高位 + 折旧尚未充分体现"有关，可持续性取决于后续供需与价格走向。看利润必须穿透折旧假设与签约周期。

PROJECT ANATOMY
一个算力租赁项目怎么跑通、怎么赚钱
7.1　交易结构：五个角色

一个典型的算力租赁项目，本质是把五类角色的资源拼在一起——很多项目里这些角色部分重叠，或由一个掮客/中介牵线。看懂谁提供什么、谁承担什么风险，是判断项目的起点。

图 · 算力租赁项目典型交易结构与资金流（实线=资金/实物，虚线=服务/持有关系）
7.2　资金流：钱怎么进、怎么出、怎么留下利润

顺着上图看现金流：客户按合同付租金 → 运营方收入；这笔收入要覆盖折旧（等同于摊还买卡的采购款或融资租赁月供）+ 机房电力费 + 运维与获客，剩下的才是利润，再在资金方与运营方之间分配。押付比例决定现金流的时间结构——卖方市场"押三付一/押二付一"让运营方先拿到钱，买方市场"押一付一"甚至先垫资，运营方现金压力陡增。合同负债（客户预付款累积）的规模，是景气度最直接的财务信号。

毛利率高端卡 + 服务化可达 60%+裸机约 20%，甚至亏损
回本周期约 1.5–2.5 年3–4 年，部分回不了本
最容易被"神话"骗到的地方

有人用"当下高租金 + 100% 满租"倒推出"几个月回本"的神话。真实的账要同时纳入利用率打折、价格回落、折旧摊满、电力与运维、以及客户违约概率。对中小/边缘玩家，这套神话往往暗藏陷阱。

7.4　合同结构：期限、押付、保底、违约
期限
大卡主流"3+2"：前 3 年闭口锁价，后 2 年按市价重议；5 年锁价已罕见。小卡随供需波动，2026 已要求 12 个月起签、部分 3 年闭口。
押付
卖方市场押三付一/押二付一；买方市场押一付一甚至先垫资。押付比例直接决定运营方的现金安全。
保底 / 违约
优质合同应含最低用量保底、违约金（如实际使用低于承诺 80% 按总价 80% 赔付）、芯片厂商连带担保等条款。
成本上涨风险
"先签闭口长约、再倒推采购成本上限拿货"的模式下，若拿货时设备价超上限，服务商要么毁约赔违约金、要么自担亏损——行业已有实际案例。
7.5　你在这单里是什么角色，就盯什么
你的角色核心该盯的东西
资金方 / 投资人资产是否真实持有与登记、折旧与残值假设是否激进、退出与回购条款、是否"名为买卖实为借贷"的融资性贸易
场地方 / 有地有电能耗审批与 PUE 合规、电力容量、上架率承诺是否有约束、别只当"机房房东"被套牢空置
卡源 / 集成方货源渠道真实性与交付确定性、认证的实际含金量、成本上涨时的履约条款
运营方下游客户与订单真实性、利用率与调度能力、押付与现金流、闭口长约下的成本敞口
下游客户 / 用算方算力的稳定性与可用吞吐、服务与运维、供应商的资金与拿卡能力（"卖的是确定性"）
08
RISKS & TRAPS
风险与陷阱：这个赛道的坑

算力租赁是骗局与资本炒作的重灾区。有从业者直言，2023 年底还有真诚建议做算力的人，到 2024 年中，"再来提议合作做算力的已经全是骗子"。以下是必须警惕的典型风险。

上市公司层面的"杀猪盘"

已有公司宣布数十亿"算力大单"，股价连板、股东户数暴增数倍，半年后合同以"零交付、零成本、零收入"终止，证监会立案调查，散户接盘。跨界玩家（做调味品的、染料的）蜂拥而入，真转型与割韭菜混杂。

空转与挖矿套利

租不出去的算力被拿去挖矿或空转套补贴。正规招商方对"纯套利、空转的，一分补贴都不给"，并分三年考核兑现、中途跑路则场地收回、补贴追回。

壳公司毁约

大客户常通过壳公司对外签约，一旦毁约则弃车保帅，壳公司不具备赔付能力，租赁方即使起诉也难获赔——"见到集团 CEO 拿到的口头承诺，东窗事发时没有任何实质作用"。违约在本行业是常态，头部厂商已发生过上亿元违约金案例。

资金链断裂

最常见的死法：盲目扩张，砸重金锁资源、租机房、招人，结果客户跟不上、闲置严重，现金流断裂直接倒闭。重资产 + 高折旧还会推高负债率。

能耗与合规红线

国家枢纽节点及能耗紧张地区要求 PUE≤1.25、绿电占比≥80%，未拿到能耗审批就开工的项目会被责令关停。

技术迭代与资产贬值

英伟达代际更替极快，旧卡账面价值快速缩水；国产卡二手市场不成熟、残值不确定。闭口长约期未满、下一代产品已上线，大客户有毁约动机。

融资性贸易（强监管）

转租链条中"名为买卖、实为借贷"的融资性贸易是强监管红线，涉国企/上市公司尤甚；监管密集问询订单真实性与披露充分性。

09
HOW TO EVALUATE
结语：项目评估框架与尽调清单

把上篇的行业地图叠回到你手上的这一单，形成四条快速判断准绳，再落到一张可执行的尽调清单。

准绳 01 · 先定位环节
看项目落在链条哪一环——是上游拿卡/贸易，还是中游 IDC/租赁/运营。上游利润厚但拼供应链与配额；中游利润薄、强周期，拼客户与调度。
准绳 02 · 再验两端
上游看货源是否真实（"空口锁货 + 先付预付款"是高危信号）；下游看客户与订单是否真实（正式合同还是框架、真实终端还是过桥转租、规模与信用是否匹配）。
准绳 03 · 穿透经济性
用采购成本、租金/差价、折旧（3 年）、电费运维搭全周期模型，并纳入价格回落与利用率打折情景；警惕靠激进残值和折旧年限调节撑起的利润。
准绳 04 · 识别真做还是蹭概念
看项目方是否具备组网、调度、运维等真实能力，还是仅充当"机房房东"或资金过桥方。这一条，往往决定项目值不值得深入。
尽调清单 · 逐项核实
01
卡从哪来？渠道、型号、交付时间是否可验证？
只有"关系"和口头承诺、要求先付大额预付款锁货、拿不出采购/交付凭证。
02
客户是谁？签的是正式合同还是框架/意向？
终端是壳公司或来路不明主体、只有框架协议、金额远超对方合理算力需求。
03
上架率/利用率实测多少？（要看日志与监控）
只给"预计满租"、拿不出真实使用日志、机房照片与远程监控。
04
合同结构：期限、押付、保底、违约金、连带担保？
无保底用量、无违约金、押付比例对己方不利、无芯片厂商担保。
05
谁承担折旧与换代风险？残值怎么算？
用激进残值（远高于 30%）撑利润、无二手回收测算、无回购条款。
06
能耗、环评、PUE、绿电、电力容量批了没？
未拿能耗审批就开工、PUE 达不到当地要求、电力容量不足。
07
交易实质：是真租赁，还是融资性贸易/资金过桥？
资金空转闭环、"名为买卖实为借贷"、涉国企上市公司的披露不充分。
综合研判：算力租赁这门生意的多与空
利好

需求端指数级增长（推理主导、Token 经济）+ 国产替代进入兑现期 + 政策强力顺风（东数西算、算力券、全国算力网），行业长期贝塔清晰。

利好

盈利正在服务化：从"卖卡时"到"卖 Token/卖服务"，具备调度、软件栈与电力资源的一体化玩家能获得毛利溢价。

需冷静

强周期 + 高杠杆 + 3 年快速折旧，高位接盘风险真实；单纯堆卡、裸机租赁是低毛利的苦生意，买方市场下大量玩家出局。

需冷静

空转套利、壳公司毁约、概念炒作与融资性贸易是这个赛道最集中的风险；已有数十亿"算力大单"零交付、被监管立案的先例。

核心结论

评估任何算力租赁项目：先定位环节、再验两端（货源与客户是否真实）、然后穿透经济性、最后识别真做还是蹭概念。这套判断，比"算力这门生意好不好"更能决定一单的成败。
